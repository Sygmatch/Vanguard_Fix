SYGMATCH
VANGUARD FIX

Es un menú interactivo (batch) llamado VANGUARD FIX & REBOOT (por MARCKO-SYGMATCH) que requiere privilegios de administrador. Sirve para solucionar problemas comunes de Riot Vanguard y League of Legends.

Opciones principales:

- 1: Cierra forzosamente los procesos de League of Legends y Riot Client.
  
- 2: Reinicia el servicio de Vanguard (`vgc`).
  
- 3: Lanza League of Legends mediante el protocolo de Riot Client.
  
- 4: Limpia la caché DNS de Windows.
  
- X: Ejecuta todo el proceso completo (cierra procesos → reinicia Vanguard → limpia DNS → relanza el juego).
  
- 0: Salir.

Ideal para cuando el cliente se queda colgado, Vanguard da errores o hay problemas de conexión.
